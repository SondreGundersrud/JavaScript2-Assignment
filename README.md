* `npm` (included with Node.js)

### Installation
Clone the repository and navigate into the project directory:
   ```bash
   git clone https://github.com/SondreGundersrud/JavaScript2-Assignment.git
   cd JavaScript2-Assignment
   ```

2. Install the project dependencies:
   ```bash
   npm install
   ```

### Usage
### Development Server
Start the local Vite development server with hot-reload:
```bash
npm run dev
```
Open the local URL shown in your terminal (typically `http://localhost:5173`) to view the app in your browser.
